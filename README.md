# OmniClaw Advanced Autonomous Agent

## Features
- Multi-agent autonomous loop
- Upgradeable skills (web research, code writing, social posting)
- Base + Monad wallet support
- $GMMC monetization + treasury
- Task marketplace
- Frontend dashboard (Vercel)
- Backend agent (Railway/Render)
- Self-upgrading skills

## Deployment
1. Deploy backend to Railway/Render.
2. Deploy frontend to Vercel.
3. Deploy OmniClawTreasury.sol to Base Mainnet.
4. Configure ENV variables in backend/frontend.
